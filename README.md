# Статистика доставок

Проста веб-програма для обліку рейсів: водій, магазин, кілометраж, кількість доставок і сума.

## Що вже є

- Додавання, редагування і видалення рейсів.
- Довідники водіїв, авто і магазинів з редагуванням.
- Прив'язка авто до кожного рейсу.
- Автоматичний розрахунок пройдених кілометрів.
- Автоматичний розрахунок суми: кількість доставок × ціна за доставку.
- Підсумки за поточним фільтром.
- Звіти по водіях, магазинах і авто.
- Експорт CSV.
- PWA-режим: можна додати сайт на головний екран телефону.

## Важливо про дані

Зараз дані зберігаються в браузері через `localStorage`.

Це означає:

- на ноутбуці будуть свої записи;
- на телефоні будуть свої записи;
- після деплою на Vercel програма відкриватиметься з будь-якого пристрою, але спільної бази між пристроями ще немає.

Щоб телефон і ноутбук бачили одні й ті самі записи, наступним кроком треба додати базу даних, наприклад Supabase або Firebase.

## Як викласти через GitHub і Vercel

1. Створи новий репозиторій на GitHub.
2. Завантаж у нього всі файли з цієї папки.
3. Зайди на [Vercel](https://vercel.com/).
4. Натисни `Add New Project`.
5. Обери свій GitHub-репозиторій.
6. У налаштуваннях Vercel нічого складного не потрібно: це звичайний статичний сайт.
7. Натисни `Deploy`.

Після деплою Vercel дасть посилання. Його можна відкрити на телефоні й ноутбуці.

Не встановлюйте програму з адреси `127.0.0.1`, `localhost` або `file://`. Це локальні адреси для розробки, вони не працюватимуть стабільно на телефоні. Для встановлення на телефон використовуйте тільки посилання Vercel.

## Як додати на телефон

На Android у Chrome: відкрий посилання Vercel, натисни меню браузера і вибери `Add to Home screen`.

На iPhone у Safari: відкрий посилання Vercel, натисни кнопку поділитися і вибери `Add to Home Screen`.
